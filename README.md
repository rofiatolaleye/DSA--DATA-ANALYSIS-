# DSA--Data-Analysis

## DSA Training Documentation

### Course topic- Practical ETL Process and Data Preparation Using Power BI

### Course overview
This class introduced us to the practical application of the ETL (Extract, Transform, Load) process in data analysis. We learned how to extract data from SQL databases, export the extracted data into CSV format, and perform ETL analysis to prepare the data for further use.

We also explored how to import the prepared dataset into Power BI Desktop, perform data modelling, and create reports to present meaningful insights from the data.

### Data Source
The dataset used for this class was extracted from a SQL database by the instructor and converted into CSV format to make it easily accessible for practical exercises. The CSV file served as the primary dataset for the ETL process, data preparation, modeling, and visualization using Power BI Desktop.

### Tool used
- Microsoft SQL Server for extracting data
- Microsoft Excel / CSV for data cleaning [Download](http://www.microsoft.com)
- Power BI Desktop (Data modelling, analysis and report building).
